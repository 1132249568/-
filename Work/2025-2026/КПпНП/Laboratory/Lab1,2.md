1. Установка Chocolatey

 Цель
Установить менеджер пакетов Chocolatey для упрощения установки программного обеспечения в Windows.

 Выполненные действия

1. Открыл PowerShell от имени администратора

2. Выполнил команду для установки Chocolatey:
   
   Set-ExecutionPolicy Bypass -Scope Process -Force; [System.Net.ServicePointManager]::SecurityProtocol = [System.Net.ServicePointManager]::SecurityProtocol -bor 3072; iex ((New-Object System.Net.WebClient).DownloadString('https://community.chocolatey.org/install.ps1'))
   

3. Проверил успешность установки:
   
   choco --version
   

 Результат
Chocolatey успешно установлен и готов к использованию.

2. Установка TeXLive

 Цель
Установить полную LaTeX-дистрибуцию TeXLive для создания PDF-документов.

 Выполненные действия

1. Установил TeXLive через Chocolatey:
   
   choco install texlive --yes
   

2. Обновил переменные среды:
   
   refreshenv
   

3. Проверил установку LaTeX:
   
   pdflatex --version
   

 Результат
TeXLive успешно установлен, команда pdflatex доступна в системе.

3. Создание базового LaTeX-файла и преобразование в PDF

 Цель
Создать простой LaTeX-документ и скомпилировать его в PDF.

 Выполненные действия

1. Создал файл first.tex с базовым содержимым:
   
 Создать LaTeX файл
@"
\documentclass{article}
\usepackage[utf8]{inputenc}
\usepackage[russian]{babel}
\begin{document}
Hey world!
\end{document}
"@ | Out-File -FilePath "first.tex" -Encoding UTF8

# 2. Скомпилировать LaTeX в PDF
pdflatex first.tex

# 3. Открыть созданный PDF файл
Invoke-Item first.pdf
   Это мой первый документ, созданный с помощью LaTeX.

 Результат
Создан файл first.pdf с базовым содержимым.

4. Создание файла с дополнениями

 Цель
Расширить документ дополнительными элементами форматирования.

 Выполненные действия

1. Создал файл second.tex с расширенным функционалом:
   
   \documentclass[a4paper,12pt]{article}
\usepackage[T1]{fontenc}
\begin{document}

Hey world!

% Новое содержимое:
Это простой
документ\footnote{со сноской}.
Это новый абзац.

\end{document}

   2. Скомпилировал расширенный документ:
   
   pdflatex second.tex
   pdflatex second.tex  # Второй раз для корректного отображения содержания
   

 Результат
Создан second.pdf с оглавлением, формулами, списками и разделами.

5. Создание файла с абзацами и пробелами
 Цель
Создать документ с правильным форматированием абзацев и управлением пробелами.

 Выполненные действия

1. Создал файл third.tex с акцентом на форматирование текста:
\documentclass{article}
\usepackage[utf8]{inputenc}
\usepackage[russian]{babel}
\begin{document}
\title{Мой первый документ}
\author{Викторов Егор}
\date{\today}
\maketitle
Первый абзац слово1 слово2 слово3

Второй абзац слово1    слово2    слово3

Третий абзац слово1\ \ \ слово2

Четвертый абзац слово1~слово2 слово3
\end{document}
2. Скомпилировал документ с форматированием:
   
   pdflatex third.tex
   

 Результат
Создан third.pdf с различными типами форматирования абзацев, пробелов и отступов.
