Структура файла библиографии **Общая структура записи:**

    @ТИП_ИСТОЧНИКА{ключ_цитирования,
      поле1 = {значение1},
      поле2 = {значение2},
      поле3 = {значение3}
    }

    @book{knuth1984,

      title     = {The TeXbook},
      publisher = {Addison-Wesley},

      isbn      = {0-201-13447-0}
    }

:::: frame
Команды цитирования

  **Команда**          **Результат**   **Применение**
  -------------------- --------------- ----------------
  `\cite{key}`         \[1\]           Базовое
  `\parencite{key}`    (Knuth, 1984)   В скобках
  `\textcite{key}`     Knuth (1984)    В тексте
  `\citeauthor{key}`   Knuth           Только автор
  `\citeyear{key}`     1984            Только год
  `\footcite{key}`     ^1^             В сноске

::: alertblock
Важно! Выбор команды зависит от стиля цитирования и контекста
использования

# Практическая часть

::: frame
Настройка документа **Подключение пакета biblatex:**

    \usepackage[
      backend=biber,        % Используем Biber
      style=gost-numeric,   % Стиль ГОСТ
      sorting=none,         % Без сортировки
      maxbibnames=99,       % Все авторы
      doi=true,             % Показывать DOI
      isbn=true,            % Показывать ISBN
      url=true              % Показывать URL
    ]{biblatex}

    \addbibresource{references.bib}

**Вывод списка литературы:**

    \printbibliography[title={Список литературы}]

Автоматизация с latexmk **Создание файла .latexmkrc:**

``` {.bash language="bash"}
$pdf_mode = 1;
$biber = 'biber %O %S';
$pdflatex = 'pdflatex -interaction=nonstopmode';
```

**Команды компиляции:**

``` {.bash language="bash"}
# Компиляция
latexmk -pdf document.tex

# Очистка временных файлов
latexmk -c

# Полная очистка
latexmk -C
```

::::::: frame
Типичные ошибки и их решение

::: alertblock
Ошибка 1: Библиография не появляется **Решение:** Проверьте
последовательность компиляции (pdflatex → biber → pdflatex → pdflatex)
:::

::: alertblock
Ошибка 2: Неправильная кодировка **Решение:** Убедитесь, что .bib файл
сохранен в UTF-8
:::

::: alertblock
Ошибка 3: Источник не цитируется **Решение:** Проверьте правильность
ключа цитирования и наличие записи в .bib
:::

::: alertblock
Ошибка 4: Неправильный формат **Решение:** Проверьте синтаксис записи в
.bib файле (запятые, скобки)

Приложение B: Команды компиляции **Вариант 1: Ручная компиляция**

``` {.bash language="bash" basicstyle="\\ttfamily\\small"}

biber document
pdflatex document.tex
pdflatex document.tex
```

**Вариант 2: С использованием latexmk**

``` {.bash language="bash" basicstyle="\\ttfamily\\small"}
latexmk -pdf -bibtex document.tex
```

**Вариант 3: Makefile**

``` {.makefile language="make" basicstyle="\\ttfamily\\small"}
all:

 pdflatex document.tex
 pdflatex document.tex
```
