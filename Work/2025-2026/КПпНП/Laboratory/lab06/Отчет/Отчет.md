# Введение

Управление библиографией является важной частью подготовки научных и
технических документов. Система LaTeX предоставляет мощные инструменты
для автоматизации этого процесса через пакеты BibTeX и biblatex
[@latex-project].

## Цель работы

Целью данной лабораторной работы является изучение методов работы с
библиографическими ссылками в системе LaTeX, освоение инструментов
BibTeX и biblatex для автоматизации создания списка литературы.

## Задачи работы

В рамках лабораторной работы необходимо решить следующие задачи:

1.  Изучить структуру файлов библиографии формата `.bib`

2.  Освоить различные типы библиографических записей

3.  Научиться использовать команды цитирования в тексте документа

4.  Изучить различные стили оформления библиографии

5.  Настроить автоматическую компиляцию документа с библиографией

6.  Создать полноценный документ с корректно оформленными ссылками

## Актуальность темы

Как отмечает @lamport1994, правильное оформление библиографических

# Теоретическая часть

## История развития систем управления библиографией

Система TeX была создана Дональдом Кнутом в конце 1970-х годов
[@knuth1984]. Одним из ключевых алгоритмов, лежащих в основе TeX,
является алгоритм разбиения абзацев на строки, описанный в работе
@knuth1977.

Позже Лесли Лампорт разработал надстройку над TeX, получившую название
LaTeX, которая значительно упростила создание структурированных
документов [@lamport1994].

## Инструменты для работы с библиографией

### BibTeX

BibTeX --- это программа и формат файлов для управления
библиографическими ссылками, разработанная Ореном Паташником
[@patashnik1988]. Основные характеристики:

- Простой текстовый формат хранения библиографических данных

- Поддержка различных типов источников (книги, статьи, веб-ресурсы)

- Автоматическая сортировка и форматирование списка литературы

- Широкая поддержка стилей оформления

Подробное описание создания стилей для BibTeX приведено в техническом
отчете @bibtex-guide.

### Biblatex и Biber

Biblatex --- это современная альтернатива BibTeX, предоставляющая
расширенные возможности [@biblatex-manual]:

- Полная поддержка Unicode

- Гибкая настройка стилей цитирования

- Расширенные возможности сортировки

- Поддержка локализации на множество языков

- Использование Biber в качестве backend-процессора [@biber-manual]

## Структура файла библиографии

Файл библиографии с расширением `.bib` содержит записи различных типов.
Каждая запись имеет следующую структуру:

``` {.latex language="TeX" caption="Общая структура BibTeX записи"}
@ТИП_ИСТОЧНИКА{ключ_цитирования,
  поле1 = {значение1},
  поле2 = {значение2},
  поле3 = {значение3}
}
```

В таблице [1](#tab:bibtex-types){reference-type="ref"
reference="tab:bibtex-types"} представлены основные типы записей BibTeX.

::: {#tab:bibtex-types}
  **Тип**            **Описание**
  ------------------ ----------------------------------------------

  `@online`          Интернет-ресурс
  `@techreport`      Технический отчет организации
  `@manual`          Техническая документация
  `@misc`            Источник, не подходящий под другие категории
  `@phdthesis`       Диссертация
  `@mastersthesis`   Магистерская диссертация

  : Основные типы BibTeX записей
:::

## Команды цитирования

Пакет biblatex предоставляет множество команд для цитирования
источников. Основные команды представлены в таблице

  **Команда**          **Пример результата**   **Использование**

  `\citeyear{key}`     1984                    Только год
  `\citetitle{key}`    The TeXbook             Только название
  `\footcite{key}`     ^1^                     Цитирование в сноске

:::

## Настройка документа

В преамбуле документа был подключен пакет biblatex с следующими
параметрами:

``` {.latex language="TeX" caption="Настройка biblatex"}
\usepackage[
  backend=biber,
  style=gost-numeric,
  sorting=none,
  maxbibnames=99,
  maxcitenames=2,
  giveninits=true,
  doi=true,
  isbn=true,
  url=true
]{biblatex}
\addbibresource{references.bib}
```

## Процесс компиляции

Для корректной работы библиографии документ необходимо компилировать в
следующей последовательности:

1.  `pdflatex report.tex` --- первая компиляция, создание `.aux` файла

2.  `biber report` --- обработка библиографии

3.  `pdflatex report.tex` --- вторая компиляция, включение библиографии

4.  `pdflatex report.tex` --- третья компиляция, обновление ссылок

Альтернативно можно использовать утилиту `latexmk`:

``` {.bash language="bash" caption="Автоматическая компиляция с latexmk"}
latexmk -pdf -bibtex report.tex
```

# Анализ результатов

## Преимущества использования biblatex

По результатам выполнения работы можно выделить следующие преимущества
использования biblatex:

1.  **Автоматизация** --- список литературы формируется автоматически на
    основе цитирований в тексте

2.  **Единообразие** --- все ссылки оформляются в едином стиле

3.  **Гибкость** --- легко изменить стиль оформления, изменив один
    параметр

4.  **Переиспользование** --- один файл `.bib` можно использовать в
    разных документах

5.  **Поддержка Unicode** --- корректная работа с кириллицей и другими
    алфавитами

## Рекомендации по использованию

На основе полученного опыта можно дать следующие рекомендации:

- Использовать biblatex вместо устаревшего BibTeX для новых проектов

- Выбирать backend=biber для полной поддержки Unicode

- Хранить библиографию в отдельном файле `.bib` для переиспользования

- Использовать менеджеры библиографии (JabRef, Zotero) для управления
  большими базами

- Регулярно делать резервные копии файла `.bib`

- Проверять корректность записей перед финальной компиляцией

# Команды компиляции

## Ручная компиляция

``` {.bash language="bash" caption="Последовательность команд компиляции"}
# Первая компиляция LaTeX
pdflatex report.tex

# Обработка библиографии
biber report

# Вторая компиляция LaTeX
pdflatex report.tex

# Третья компиляция для обновления ссылок
pdflatex report.tex
```

## Автоматическая компиляция

``` {.bash language="bash" caption="Использование latexmk"}
# Компиляция с автоматической обработкой библиографии
latexmk -pdf -bibtex report.tex

# Очистка вспомогательных файлов
latexmk -c

# Полная очистка (включая PDF)
latexmk -C
```
