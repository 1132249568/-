# textwidth vs linewidth

::::::::: frame
Разница между textwidth и linewidth

::::::: columns
:::: column
0.48

::: block
`\textwidth`

- Полная ширина текстовой области

- Не меняется внутри окружений

- Постоянная величина
:::
::::

:::: column
0.48

::: block
`\linewidth`

- Текущая ширина строки

- Меняется в колонках, списках

- Адаптивная величина
:::
::::
:::::::

::: alertblock
Важно! В режиме `twocolumn` значения различаются!
:::
:::::::::

:::: frame
Визуализация: textwidth vs linewidth

::: center
:::
::::

:::: frame
Пример использования

::: exampleblock
Одна колонка

    \documentclass{article}
    \begin{document}
    \includegraphics[width=0.8\textwidth]{image.png}
    \includegraphics[width=0.8\linewidth]{image.png}
    \end{document}
:::

**Примечание:** В одноколоночном режиме `textwidth` и `linewidth` дают одинаковый результат!
::::

::::: frame
Пример с twocolumn

::: exampleblock
Две колонки

    \documentclass[twocolumn]{article}
    \begin{document}
    \includegraphics[width=0.8\textwidth]{img.png}

    \includegraphics[width=0.8\linewidth]{img.png}
    \end{document}
:::

::: alertblock
Важно! С `textwidth` изображение выйдет за пределы колонки!\
С `linewidth` --- правильно впишется в колонку.

# Плавающие объекты (floats)

::::::: frame
Что такое плавающие объекты?

::: block
Определение Плавающие объекты (floats) --- это элементы, которые LaTeX может перемещать для оптимального размещения на странице.
:::

::::: columns
::: column
0.48 **Типы floats:**

- `figure` --- рисунки

- `table` --- таблицы
:::

::: column
0.48 **Преимущества:**

- Автоматическая нумерация

- Список рисунков/таблиц

- Оптимальное размещение
:::
:::::
:::::::

:::: frame
Спецификаторы позиции

   **Спец.**  **Название**   **Описание**
  ----------- -------------- ------------------------------
      `h`     here           Примерно здесь
      `t`     top            Вверху страницы
      `b`     bottom         Внизу страницы
      `p`     page           На отдельной странице
      `!`     override       Игнорировать ограничения
      `H`     HERE           Строго здесь (пакет `float`)

::: exampleblock
Примеры `[htbp]` --- попробовать h, затем t, затем b, затем p\
`[!h]` --- здесь, игнорируя ограничения\
`[H]` --- строго здесь (требует `\usepackage{float}`)
:::
::::

:::::: frame
Взаимодействие спецификаторов

::: center
:::

::: alertblock
Важно! LaTeX пробует варианты **слева направо** в порядке указания
:::

::: block
Рекомендация Используйте `[htbp]` для максимальной гибкости
:::
::::::

::::: frame
Пример плавающего объекта

::: exampleblock
Код

    \begin{figure}[htbp]
        \centering
        \includegraphics[width=0.6\textwidth]{image.png}
        \caption{Podpis k risunku}
        \label{fig:example}
    \end{figure}

    Ssylka na risunok: sm. ris.~\ref{fig:example}.
:::

::: alertblock
Порядок важен! `\label` должна идти **после** `\caption`!

# Метки и ссылки

::::: frame
Система меток и ссылок

::: block
Основные команды

- `\label{метка}` --- создать метку

- `\ref{метка}` --- ссылка на номер

- `\pageref{метка}` --- ссылка на страницу
:::

::: exampleblock
Соглашения об именовании

- `fig:` --- для рисунков

- `tab:` --- для таблиц

- `eq:` --- для уравнений

- `sec:` --- для разделов
:::
:::::

::::: frame
Сколько прогонов нужно?

::: center
:::

::: alertblock
Правило Минимум **2 прогона** для корректных ссылок!
:::
:::::

::::::::: frame
Эксперимент: label до caption

::::::: columns
:::: column
0.48

::: block
Неправильно

    \begin{figure}[h]
        \centering
        \label{fig:wrong}
        \caption{Risunok}
    \end{figure}

**Результат:** ссылка на номер **раздела**, а не рисунка!
:::
::::

:::: column
0.48

::: block
Правильно

    \begin{figure}[h]
        \centering
        \caption{Risunok}
        \label{fig:correct}
    \end{figure}

**Результат:** правильная ссылка на рисунок!
:::
::::
:::::::

::: alertblock
Запомните! `\label` всегда **после** `\caption`!
:::
:::::::::

:::::::::: frame
Эксперимент: label для уравнений

::::::: columns
:::: column
0.48

::: block
Правильно

    \begin{equation}
        E = mc^2
        \label{eq:einstein}
    \end{equation}

**Работает!**
:::
::::

:::: column
0.48

::: block
Неправильно

    \begin{equation}
        E = mc^2
    \end{equation}
    \label{eq:wrong}

**Не работает!**
:::
::::
:::::::

::: alertblock
Важно! Для уравнений `\label` должна быть **внутри** окружения `equation`!
:::

::: exampleblock
Почему? После `\end{equation}` счётчик уже не активен

# Выводы

::: frame
Основные выводы

1.  **Параметры изображений:**

    - width, height, scale, angle работают независимо

    - Можно комбинировать для нужного эффекта

2.  **textwidth vs linewidth:**

    - В одной колонке --- одинаковы

    - В twocolumn --- linewidth меньше

3.  **Плавающие объекты:**

    - Спецификаторы \[htbp\] дают гибкость

    - LaTeX выбирает оптимальное размещение

4.  **Метки и ссылки:**

    - Нужно минимум 2 прогона компиляции

    - label после caption для floats

    - label внутри equation для уравнений
:::

:::::: frame
Практические рекомендации

::: block
Для изображений

- Используйте `width=0.X\linewidth`

- Добавляйте `keepaspectratio=true`

- Сохраняйте изображения в высоком разрешении
:::

::: block
Для floats

- Всегда используйте `\centering`

- Добавляйте информативные подписи

- Используйте осмысленные метки (fig:name)
:::

::: block
Для компиляции

- Компилируйте 2-3 раза для ссылок

- Проверяйте предупреждения в логе

- Используйте latexmk для автоматизации
