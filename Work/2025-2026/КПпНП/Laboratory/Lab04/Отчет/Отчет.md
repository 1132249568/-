# Введение

Данная лабораторная работа посвящена изучению возможностей системы LaTeX по работе с графическими элементами, плавающими объектами и системой перекрестных ссылок.

## Цель работы

Целью данной работы является освоение практических навыков работы с изображениями в LaTeX, изучение параметров позиционирования графики и механизма перекрестных ссылок.

В рамках лабораторной работы необходимо выполнить следующие задачи:

1.  Создать собственные изображения с использованием пакета TikZ

8.  Исследовать правильное размещение label относительно caption

# Теоретическая часть

## Пакет graphicx

Пакет `graphicx` является стандартным инструментом для включения изображений в документы LaTeX. Основная команда для вставки изображений:

    \includegraphics[параметры]{имя_файла}

## Параметры изображений

Основные параметры команды `includegraphics`:

- **width** --- ширина изображения

- **height** --- высота изображения

- **scale** --- масштаб изображения

- **angle** --- угол поворота изображения

- **keepaspectratio** --- сохранение пропорций

## Плавающие объекты

Плавающие объекты (floats) в LaTeX позволяют системе автоматически размещать изображения и таблицы в оптимальных местах документа. Спецификаторы позиции:

::: {#tab:specifiers}
   **Спецификатор**  **Описание**
  ------------------ ------------------------------------
          h          here --- примерно в месте вставки
          t          top --- вверху страницы
          b          bottom --- внизу страницы
          p          page --- на отдельной странице
          !          игнорировать некоторые ограничения
          H          строго здесь (требует пакет float)

  : Спецификаторы позиционирования
:::

## Работа с командами label и ref

### Количество компиляций

Для корректной работы перекрестных ссылок требуется **минимум две компиляции**:

1.  **Первая компиляция:** LaTeX записывает информацию о метках в файл .aux

2.  **Вторая компиляция:** LaTeX читает информацию из .aux и подставляет правильные номера

Создадим несколько разделов для демонстрации:

# Тестовый раздел для ссылок {#sec:test1}

Это раздел [4](#sec:test1){reference-type="ref" reference="sec:test1"}. Он содержит подраздел [4.1](#subsec:test1_1){reference-type="ref" reference="subsec:test1_1"}.

## Тестовый подраздел {#subsec:test1_1}

Ссылка на основной раздел: раздел [4](#sec:test1){reference-type="ref" reference="sec:test1"}.

## Еще один подраздел {#subsec:test1_2}

Ссылки на предыдущие разделы: [4](#sec:test1){reference-type="ref" reference="sec:test1"}, [4.1](#subsec:test1_1){reference-type="ref" reference="subsec:test1_1"}, [4.2](#subsec:test1_2){reference-type="ref" reference="subsec:test1_2"}.

## Правильное размещение label относительно caption

### Неправильное размещение (label перед caption)

Если поместить `label` **перед** `caption`, ссылка будет указывать на номер раздела, а не на номер рисунка:

    \begin{figure}[h]
    \centering
    [изображение]
    \label{fig:wrong}  % НЕПРАВИЛЬНО!
    \caption{Подпись}
    \end{figure}

<figure id="fig:wrong_order" data-latex-placement="h">

### Правильное размещение (label после caption)

Правильный порядок: `caption` **затем** `label`:

    \begin{figure}[h]
    \centering

    \caption{Подпись}
    \label{fig:correct}  % ПРАВИЛЬНО!
    \end{figure}

## Label для уравнений

### Правильное размещение label в уравнении

Для уравнений `label` должен быть **внутри** окружения equation:

$$\begin{equation}
E = mc^2
\label{eq:einstein}
\end{equation}$$

Ссылка на уравнение [\[eq:einstein\]](#eq:einstein){reference-type="ref" reference="eq:einstein"} работает корректно.

### Неправильное размещение (label после endequation)

Если поместить label **после** `end{equation}`, ссылка будет некорректной:

$$\begin{equation}
F = ma
\end{equation}$$ []{#eq:newton_wrong label="eq:newton_wrong"}

Попытка сослаться на уравнение: [\[eq:newton_wrong\]](#eq:newton_wrong){reference-type="ref" reference="eq:newton_wrong"} --- даст номер раздела, а не уравнения!

### Правильный пример

$$\begin{equation}
\int_{a}^{b} f(x)dx = F(b) - F(a)
\label{eq:fundamental}
\end{equation}$$ Уравнение [\[eq:fundamental\]](#eq:fundamental){reference-type="ref" reference="eq:fundamental"} демонстрирует основную теорему математического анализа.

# Эксперименты с двухколоночным режимом

Для демонстрации поведения изображений в режиме `twocolumn` создадим отдельный пример.

## Поведение textwidth и linewidth в twocolumn

В режиме `twocolumn`:

- `textwidth` --- полная ширина страницы

- `linewidth` --- ширина одной колонки

- `columnwidth` --- ширина колонки (равна linewidth)

## Изображения на всю ширину страницы

Для размещения изображения на всю ширину в режиме twocolumn используется окружение `figure*`:

    \begin{figure*}[t]
    \centering
    \includegraphics[width=\textwidth]{image}
    \caption{Изображение на всю ширину}
    \end{figure*}

## Спецификаторы позиционирования

Результаты тестирования спецификаторов:

1.  **\[h\]** --- пытается разместить здесь, но может переместить

## Система перекрестных ссылок

Основные выводы по работе с `label` и `ref`:

- Требуется **минимум 2 компиляции** для корректной работы ссылок

- Для сложных документов может потребоваться 3-4 компиляции

- `label` должен идти **после** `caption` для рисунков и таблиц

- `label` должен быть **внутри** окружения equation

- Неправильное размещение приводит к ссылкам на номер раздела вместо объекта
