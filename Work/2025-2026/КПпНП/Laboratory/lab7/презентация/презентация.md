# Структура постера и колонки

:::: frame
Основы работы с колонками **Окружение columns** позволяет создавать
многоколоночные макеты

    \begin{columns}
      \column{.33}
      % Первая колонка (33% ширины)
      
      \column{.33}
      % Вторая колонка (33% ширины)
      
      \column{.33}
      % Третья колонка (33% ширины)
    \end{columns}

::: alertblock
Важно! Числовое значение определяет относительную ширину колонки (от 0
до 1)
:::
::::

:::: frame
Визуализация колонок

::: center
:::
::::

::: frame
Колонки различной ширины **Асимметричный макет** для разных типов
контента:

    \begin{columns}
      \column{.7}
      % Широкая колонка (70% ширины)
      \block{Основные результаты}{
        Здесь размещается основной контент,
        графики, таблицы
      }
      
      \column{.3}
      % Узкая колонка (30% ширины)
      \block{Дополнительно}{
        Ссылки, определения, примечания
      }
    \end{columns}

# Работа с блоками контента

:::::: frame
Базовый синтаксис блоков **Команда \\block** создает блок контента:

    \block{Заголовок блока}{
      Содержимое блока может включать:
      - Текст
      - Списки
      - Формулы
      - Изображения
    }

::::: columns
::: column
0.5 **С заголовком:**

    \block{Заголовок}{Текст}
:::

::: column
0.5 **Без заголовка:**

    \block{}{Текст}
:::
:::::
::::::

::: frame
Добавление заметок к блокам **Команда \\note** создает заметку со
стрелкой:

    \block{Заголовок}{
      Основное содержимое блока
      \vspace{2cm}  % Место для заметки
    }

    \note[targetoffsetx=5cm, 
          targetoffsety=-3cm, 
          width=8cm]{
      Это заметка, указывающая на блок выше
    }
:::

::::: frame
Параметры заметок

::: block
Основные параметры команды \\note

`targetoffsetx`

:   Горизонтальное смещение стрелки относительно центра блока

`targetoffsety`

:   Вертикальное смещение стрелки

`width`

:   Ширина текстового блока заметки
:::

::: alertblock
Не забудьте! Используйте `\vspace` для создания пространства под заметку
в основном блоке

# Вставка графических элементов

:::: frame
Особенности работы с изображениями

::: alertblock
Важное ограничение! В tikzposter **нельзя** использовать окружение
`figure`
:::

**Вместо этого используется:**

- Окружение `center`

- Команда `\captionof{figure}{...}`

- Пакет `caption` (обязательно!)

<!-- -->

    % В преамбуле:
    \usepackage{caption}
::::

:::: frame
Вставка растровых изображений

    \block{Результаты эксперимента}{
      \begin{center}
        \includegraphics[width=0.8\textwidth]{image.png}
        \captionof{figure}{Подпись к изображению}
      \end{center}
    }

::: block
Поддерживаемые форматы

- PNG --- для скриншотов и растровой графики

- JPG --- для фотографий

- PDF --- для векторной графики

# Работа с цветовым оформлением

::::: frame
Ограничения tikzposter

::: alertblock
Важное ограничение! Пакет tikzposter **не поддерживает** опцию
`svgnames` пакета xcolor
:::

**Это означает, что недоступны:**

- `Red`, `Blue`, `Green`

- `ForestGreen`, `RoyalBlue`

- Другие именованные цвета SVG

::: block
Решение Все цвета должны быть определены вручную с помощью
`\definecolor`
:::
:::::

:::: frame
Определение пользовательских цветов **В преамбуле документа:**

    \definecolor{MyPink}{RGB}{194, 19, 182}
    \definecolor{MyBlue}{RGB}{0, 102, 204}
    \definecolor{MyGreen}{RGB}{34, 139, 34}
    \definecolor{MyOrange}{RGB}{255, 140, 0}

::: block
Цветовые модели

RGB

:   Красный, Зеленый, Синий (0-255)

HTML

:   Шестнадцатеричный код (#RRGGBB)

cmyk

:   Голубой, Пурпурный, Желтый, Черный (0-1)
:::
::::

:::: frame
Использование цветов в тексте

    Обычный черный текст, 
    \color{MyPink} розовый текст, 
    \color{black} снова черный текст.

**Результат:**

Обычный черный текст, розовый текст, снова черный текст.

::: alertblock
Важно! После использования `\color` все последующий текст будет этого
цвета, пока не будет задан другой цвет

# Полный пример постера

::: frame
Структура документа

``` {basicstyle="\\ttfamily\\tiny"}
\documentclass[25pt, a0paper, portrait]{tikzposter}
\usepackage[utf8]{inputenc}
\usepackage[russian]{babel}
\usepackage{caption}

\definecolor{MyPink}{RGB}{194, 19, 182}
\definecolor{MyBlue}{RGB}{0, 102, 204}

\title{Название исследования}
\author{Автор}
\institute{Университет}

\begin{document}
\maketitle

% Содержимое постера

\end{document}
```
:::

::: frame
Пример содержимого постера (1/2)

``` {basicstyle="\\ttfamily\\tiny"}
\begin{columns}
  \column{.5}
  \block{Введение}{
    Краткое описание проблемы и актуальности 
    исследования. Постановка задачи.
  }
  
  \block{Методы}{
    \begin{itemize}
      \item Описание используемых методов
      \item Экспериментальная установка
      \item Параметры эксперимента
    \end{itemize}
  }
```
:::

::: frame
Пример содержимого постера (2/2)

``` {basicstyle="\\ttfamily\\tiny"}
\column{.5}
  \block{Результаты}{
    \begin{center}
      \includegraphics[width=0.9\textwidth]{results.png}
      \captionof{figure}{Основные результаты эксперимента}
    \end{center}
  }
  
  \block{Выводы}{
    \begin{enumerate}
      \item Первый важный вывод
      \item Второй важный вывод
      \item Перспективы дальнейших исследований
    \end{enumerate}
  }
\end{columns}
```

:::: frame
Типичные ошибки

::: alertblock
Чего следует избегать

- Слишком много текста --- постер превращается в статью

- Мелкий шрифт --- информация нечитаема

- Слишком много цветов --- пестрота и хаос

- Низкое качество изображений --- непрофессиональный вид

- Отсутствие структуры --- сложно следить за логикой

- Неправильные пропорции колонок --- неэффективное использование
  пространства
:::

5.  **Воспроизводимость** --- легко обновлять и модифицировать

6.  **Качество** --- векторная графика для печати
