# Теоретическая часть

## Основы создания таблиц в LaTeX

Для создания таблиц в LaTeX используется окружение `tabular`. Базовый
синтаксис:

    \begin{tabular}{спецификация_столбцов}
        содержимое таблицы
    \end{tabular}

## Спецификация столбцов

Спецификация столбцов определяет количество столбцов и выравнивание
содержимого в них:

- `l` --- выравнивание по левому краю (left)

- `c` --- выравнивание по центру (center)

- `r` --- выравнивание по правому краю (right)

- `|` --- вертикальная линия между столбцами

Например, `{|l|c|r|}` создаёт таблицу с тремя столбцами и вертикальными
линиями.

## Разделители в таблице

- `&` --- разделитель ячеек в строке

- `\\` --- конец строки

- `\hline` --- горизонтальная линия

## Команда multicolumn

Синтаксис команды `\multicolumn`:

    \multicolumn{количество_столбцов}{выравнивание}{содержимое}

Эта команда позволяет объединить несколько столбцов в один.

# Практическая часть

## Эксперимент 1: Простая таблица

Создана базовая таблица 3×3 с различными типами выравнивания:

::: center
  Левый    Центр    Правый
  ------- ------- --------
  Текст    Текст     Текст
  123       456        789
:::

**Код:**

    \begin{tabular}{|l|c|r|}
    \hline
    Левый & Центр & Правый \\
    \hline
    Текст & Текст & Текст \\
    \hline
    123 & 456 & 789 \\
    \hline
    \end{tabular}

## Эксперимент 2: Выравнивание по левому краю

Таблица с выравниванием всех столбцов по левому краю:

::: center
  Имя         Фамилия   Возраст
  ----------- --------- ---------
  Иван        Иванов    25
  Мария       Петрова   30
  Александр   Сидоров   28
:::

**Результат:** Все данные выровнены по левому краю, что удобно для
текстовой информации.

## Эксперимент 3: Выравнивание по центру

Таблица с центральным выравниванием:

::: center
     Товар     Количество   Цена
  ----------- ------------ ------
    Яблоки         10       100
     Груши         5        150
   Апельсины       8        200
:::

**Результат:** Содержимое всех ячеек расположено по центру, таблица
выглядит симметрично.

## Эксперимент 4: Выравнивание по правому краю

Таблица с выравниванием по правому краю (удобно для числовых данных):

::: center
     Год     Доход    Расход
  ------ --------- ---------
    2021   1000000    800000
    2022   1200000    900000
    2023   1500000   1000000
:::

**Результат:** Числовые данные выровнены по правому краю, что облегчает
их сравнение.

## Эксперимент 5: Комбинированное выравнивание

Таблица с различными типами выравнивания в разных столбцах:

::: center
  Название (слева)    Категория (центр)    Цена (справа)
  ------------------ ------------------- ---------------
  Ноутбук                Электроника               50000
  Книга                  Литература                  500
  Стул                     Мебель                   3000
:::

**Результат:** Каждый столбец имеет оптимальное выравнивание для своего
типа данных.

## Эксперимент 6: Недостаточное количество элементов

Исследование поведения LaTeX при указании меньшего количества элементов,
чем столбцов:

::: center
  Столбец 1        Столбец 2    Столбец 3   Столбец 4
  --------------- ----------- ----------- -----------
  Полная строка     Данные            100         200
  Только два       элемента               
  Один                                    
  Все четыре        столбца     заполнены       здесь
:::

**Результат:** LaTeX успешно компилирует таблицу, оставляя пустые ячейки
справа. Ошибок не возникает.

## Эксперимент 7: Избыточное количество элементов

При попытке указать больше элементов, чем объявлено столбцов, возникает
ошибка компиляции:

`! Extra alignment tab has been changed to \cr.` Это означает, что
количество элементов превышает количество объявленных столбцов.

## Эксперимент 8: Базовое использование multicolumn

Объединение столбцов для создания заголовка таблицы:

::: center
+-------------------------------------+
| **Заголовок таблицы**               |
+:========+:=======:+================:+
| Имя     | Возраст | Город           |
+---------+---------+-----------------+
| Иван    | 25      | Москва          |
+---------+---------+-----------------+
| Мария   | 30      | Санкт-Петербург |
+---------+---------+-----------------+
:::

**Код:**

    \multicolumn{3}{|c|}{\textbf{Заголовок таблицы}}

**Результат:** Три столбца объединены в один с центральным
выравниванием.

## Эксперимент 9: Объединение двух столбцов

::: center
+---------+---------------------+-------+
| Продукт | Характеристики      | Цена  |
+:========+:=======:+:=========:+======:+
| Телефон | Память  | 128 ГБ    | 30000 |
+---------+---------+-----------+-------+
| Планшет | Экран   | 10 дюймов | 25000 |
+---------+---------+-----------+-------+
:::

**Результат:** Два средних столбца объединены для создания общего
заголовка.

## Эксперимент 10: Сложная таблица

Создание сложной таблицы с несколькими уровнями заголовков:

+---------+-------+-------+-------+-------+
| Q1      | 100   | 110   | 80    | 85    |
+---------+-------+-------+-------+-------+
| Q2      | 120   | 115   | 90    | 88    |
+---------+-------+-------+-------+-------+
| Q3      | 130   | 140   | 95    | 100   |
+---------+-------+-------+-------+-------+

+---------+-------+-------+-------+-------+

**Результат:** Создана многоуровневая таблица с объединёнными ячейками
на разных уровнях.

# Выводы

По результатам выполнения лабораторной работы были получены следующие
выводы:

1.  **Выравнивание содержимого:**

    - Тип `l` (левое) оптимален для текстовых данных

    - Тип `c` (центральное) подходит для заголовков и симметричного
      отображения

    - Тип `r` (правое) удобен для числовых данных и финансовых
      показателей

    - Комбинирование типов выравнивания повышает читаемость таблиц

2.  **Обработка ошибок количества элементов:**

    - При недостатке элементов LaTeX создаёт пустые ячейки без ошибок

    - При избытке элементов возникает ошибка компиляции

    - Важно строго соблюдать соответствие между объявленным и
      фактическим количеством столбцов

3.  **Использование multicolumn:**

    - Команда `\multicolumn` позволяет гибко объединять столбцы

    - Можно создавать многоуровневые заголовки

    - Для каждого объединения можно задать индивидуальное выравнивание

    - Синтаксис: `\multicolumn{n}{align}{text}`

4.  **Практические рекомендации:**

    - Использовать подходящее выравнивание для каждого типа данных

    - Применять `multicolumn` для улучшения структуры сложных таблиц

    - Использовать горизонтальные и вертикальные линии для повышения
      читаемости

5.  **Освоенные навыки:**
